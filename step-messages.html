2
GitHub 토큰 발급
github.com/settings/tokens → Generate new token (classic) → repo 체크 → 생성 후 복사
3

채팅에 내 GitHub 토큰: ghp_XXXX... 입력하시면 즉시 push 진행합니다
4
GitHub Pages 활성화
저장소 → Settings → Pages → Source: Deploy from a branch → Branch: main → / (root) → Save
